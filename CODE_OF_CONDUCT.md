# Code of conduct

This is a small, friendly project for people who play Star Citizen and like building tools around it. We want
contributing here to be pleasant for everyone, whatever their experience, language or play style.

## What we expect

- Be kind and assume good faith. Critique code and ideas, never the person.
- Be patient with newcomers and with slow replies: this is a hobby project.
- Say what you tried and what happened when you report a problem; say what you need when you ask for a feature.
- Credit other people's work, including the data sources this project depends on.

## What we do not accept

- Harassment, insults, discrimination, or personal attacks, in issues, pull requests or anywhere the project is discussed.
- Posting other people's private information, including game handles linked to real identities, tokens or logs that
  contain them. Redact your `Game.log` before sharing a snippet.
- Pushing the project toward things its rules forbid: scraping websites, reading game memory, automating the game,
  or tools that write to remote services. See [SECURITY.md](SECURITY.md).

## Scope and enforcement

This applies to all project spaces. The maintainer may edit or remove comments, close issues, or block users who
break these rules. To report a problem, open a private security advisory on the repository (Security tab) and
choose "Report a vulnerability" as the channel for it, or contact the maintainer on GitHub.
